# AI 分析工作台：交互改版说明

## 本次使用方式

从顶部「AI 工作台」或右下角入口进入独立工作区。桌面左侧保留简短会话，右侧是完整分析页面；窄屏上下排列。企业详情页进入时沿用当前企业和年度，也可直接输入企业名称或六位代码。

1. 提问后显示动态主光球与查找、分析、校验进度。
2. 收到完整结果后自动定位分析页面，按事实、判断、服务思路、服务建议、待沟通问题整理。不会把模型文字直接执行为网页。
3. 真实依据以不同颜色的立体光球依次浮现，轻微悬浮。点击打开原文、产品、企业或待核实详情；超过五个时可展开全部。同名依据仍分别可访问。
4. 「重新生成」再次提交上一个问题；「新对话」结束当前生成并开始新会话；「停止」取消本地接收。上游不支持取消时仍可能继续运行。
5. 分析结果使用 #analysis=结果编号 地址。刷新可恢复本身份的当前会话及已完成页面，历史回复可以重新展开。新对话不会删除服务端分析，但当前版本没有跨会话历史列表；需回看旧会话的结果时可先保留其地址。
6. 结果页支持继续追问、查看企业、生成访前简报、复制结果、打印或另存 PDF。

## 刷新的边界

已完成分析可恢复；正在生成时刷新不会自动续接原来的数据流，可重新提问。会话恢复依赖浏览器本地保存的会话编号，分析数据仍在后端，读取时验证所属用户。切换演示身份不会显示其他身份的分析。

## 技术接入与发布

保留既有 Coze / LangGraph / 本地规则引擎选择方式。本次改造主要是网页呈现与会话恢复，不替换已打通的云端工作流。后端新增会话消息的 analysis_id、question，以及已保存分析的 question 字段；不需要数据库结构迁移。

需同步发布 web 目录及 server/chat.py、server/analysis_service.py、server/local_engine.py，并重启应用服务；仅更新静态网页不能获得完整的历史结果恢复能力。发布继续沿用现有环境变量与持久化数据库配置。版本查询参数已更新。本次未操作云端发布。

## 验证

- 后端：现有回归测试及新增的分析恢复、原问题恢复、指定年度、跨身份隔离测试。
- 前端：数据流逐字节拆包、中文编码、CRLF、多行内容、异常传播与读锁释放测试。
- 浏览器：实际提问生成、按 2022 年展示结果、光球打开年报原文、刷新恢复分析与历史回复入口；桌面双栏和窄屏布局检查。
- 本地浏览器验证使用规则引擎；云端真实 AI 的措辞质量与响应速度仍需在发布后验收。
