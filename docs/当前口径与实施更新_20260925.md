## 三、全部主张与需求主张如何区分

主张是从文本中抽出的独立陈述，一块文本可以有多个主张。**全部主张是抽取结果全集；需求主张是其中满足需求标签的子集**，不是两套重复计数的数据。

| 主张标签 | 数量 | 算不算需求主张 | 解释 |
|---|---:|---|---|
| 经营部署 | 1,789 | 是 | 按研究规则识别的、具有具体实施安排的需求陈述 |
| 战略意图 | 2,278 | 是 | 按研究规则识别的未来出海方向与意向 |
| 已有出海行为 | 12,209 | 否 | 已发生的业务或布局，可供背景分析，不直接代表新增需求 |
| 出海口号 | 1,566 | 否 | 泛化表述，未满足需求判定条件 |
| 出海无关 | 5,876 | 否 | 被抽取后判为不属于出海需求的陈述 |
| **全部主张** | **23,718** | — | 五类之和 |
| **需求主张** | **4,067** | — | 经营部署+战略意图 |

示意：“公司已在越南设厂”属于已有行为；“计划新建越南生产基地”在满足具体规则时属于需求主张；“坚持国际化发展”不能仅凭出现国际化就视为需求。

落地约定：数据库保留五类；名单、热度和当年产品匹配只消费两类需求主张；原文证据可以展示其他主张但明确标签。`/api/meta` 分别返回 all/demand，`/api/evidence` 每个主张增加 is_demand。严禁把23,718写成“23,718条出海需求”或“全部通过人工验证”。

单位始终区分：317家企业、1,594个面板企业年度、37,946块有效文本、23,718条全部主张、4,067条需求主张。需求聚合有983个企业年度，其中981个年度标签为正、2个年度标签不完整但有需求线索。

## 六、Neo4j 与供应链边界

现有应用使用 SQLite 展示证据关系及有限供应链画像。已移除应用中“设置 NEO4J_URI 自动切换”的运行分支，避免设计预留被误读为已实现。

项目书可写：银行未来提供在授权范围内可识别的交易对手及交易关系后，可通过适配接口映射统一企业ID、关系类型、年度/有效期、金额、来源与授权范围，接入Neo4j进行关联检索。本项目只描述此系统设计，不交付银行数据接口联调、实名图谱或全量供应链。

当前匿名“客户一/供应商一”等仅表示单个披露主体和年度下的排名，不能作为跨公司共用的企业节点。保留原有前五大客户/供应商、集中度及来源提供的有限网络信息；不声称拥有全量关系。文本具名客户改为“提及线索”关系，不把计划合作直接当已发生交易。

**后续修订（多跳与名称判定）**：前端“二跳传导链”区块及 `sc_of()`／`supply_chain()` 的多跳字段均已移除——原实现既缺少数据支撑（`network` 表 95 行中仅 2 行两跳齐全，且均为 2019 年），又在第二跳缺失时对 NaN 取整导致 16 家企业的供应链接口返回 500。现统一为**单跳画像**，**多跳关联检索归入 Neo4j 扩展设计**，不作为本期能力输出，也不描述为“供应链传导预测”。同时交易对手名称的境外标记改用名称专用判定（`geo_extract_name`，只认名称开头或分隔符片段内的国别词），修复「上海顺斯德国际贸易有限公司 → 德国」这类中文字串误命中；正文场景仍按子串匹配，召回不变。

## 十一、年份一致性与统计范围

本轮实际落实：

1. 显式year始终保留；该年没有数据就返回缺失，不回退至其他年份，即使旧调用传strict_year=False。
2. 未指定year时，企业详情、评分、推理链、简报、图谱和供应链统一以该企业最新可用面板/文本年度为准，不再各自选择最新信号年。
3. 当年需求、产品匹配、文本客户只取所选年；以前的需求单列历史，之后的披露不倒灌。
4. 新国别仍与year之前的布局比较；子公司国别采用截至year曾记录集合，界面说明其不是当期存续断言。
5. 能力评分和客户集中度分位只与同年度样本比较；简报删除跨年固定“样本中位32%”文案。
6. 产业细分统计跟随年份/省份/行业；选全期才按全期企业去重。
7. 雷达接口返回真实total与展示items；页面明确“总计/当前展示”，不把最多200行称为全部。
8. 前端详情切换增加请求代次保护，较早请求不能覆盖后选企业；默认解析出来的年度写入对话上下文。

时间边界：当前历史年度字段是年报所属年度，不是披露日。此修复阻止不同报告年度混用，但不宣称已经实现交易日级“当时已公开信息”的回测；后者需要披露时间数据。

热度公式仍为2×部署+意图+硬锚点数+min(方向数,3)−1。它描述所选年度披露强度，不是出海概率、模型置信度或融资额度。长年报及拆分数量会影响分值，因此保留可解释规则，不把它包装为经过预测校准的概率。
