## 0. 为什么要改（3 句）

AI 回答时会写「这句话出自哪份年报哪一段」的引用。但它现在**会把工具返回里的字段名当成引用**
（例如把 `filter_explanation` 写成 `ev:filter_explanation`、把股票代码写成 `ev:item:300827`），
这些引用在后端校验时全部被判非法并剥离 → **页面上「原文依据」光球消失、正文里点不出依据**。

本次改动就是让 AI **写对引用**，并加一道**确定性校验**防止它再写错。改完后的效果：

- 正文每段旁边重新出现「依据 N ↗」按钮；
- 点光球能高亮正文对应段落、打开年报原文；
- 不再出现 `[bad_ref] …已移除` 的告警。

**改动一共 4 处**：①N07 提示词 ②N05/N06 记录引用 ③N08 加过滤 ④重新部署。

## 1. 改动一：N07（AI 分析节点）的提示词

**位置**：工作流里 N07 那个大模型节点的**系统提示词（System Prompt）**。
**操作**：在**末尾**追加下面这一整段（原有的 16 条不要动）。

```text
【引用规则（硬性）】
1. refs / evidence_refs / product_source_refs / orbs[].ref_id 里每个值，
   都必须逐字复制自本轮工具响应中出现的引用字符串，不得改写、拼接、缩写或自造。
2. evidence 引用格式固定为四段：ev:<chunk_id>:<claim_number>:<text_version>。
   chunk_id 形如 v21_c00020485，claim_number 是数字，text_version 是快照文本哈希。
3. 严禁把工具响应中的字段名或业务字段当作引用，例如
   ev:filter_explanation、ev:item:<股票代码>、ev:scode、ev:coname 一律为非法引用。
4. 严禁用股票代码、企业名称、排名序号拼造 chunk_id。
5. 如果某个结论在工具响应里找不到对应的引用，就把该处 refs 留为空数组 []，
   并在正文中说明"该项为规则推断/待核实"，宁缺毋造。
6. 不得输出 URL、HTML、脚本或图片链接。
7. orbs 字段的两种合法写法（二选一，不要写半套）：
   (a) 完全省略 orbs，或写成空数组 [] —— 由后端自动补建证据球与产品球；
   (b) 完整给出，并且至少包含一个 evidence 类型的光球
       （kind="evidence"，ref_id 为合法 ev: 引用）。
   只给 product 光球而不给 evidence 光球的"半套写法"会阻止后端兜底，
   导致页面上没有原文证据可点。
```

> 说明：第 7 条是关键补丁。原来的行为是"给了 3 个产品球但没有证据球"，这会让后端的自动补建
> 逻辑不执行（后端只在"完全没有光球"时才补建）——**半套比不给更糟**。

## 2. 改动二：N05、N06 记录本轮真实引用

**位置**：N05（事实检索）与 N06（资料检索）这两个插件节点所在的处理代码。
**操作**：每次调完工具、拿到响应后，把响应里出现过的引用收集起来，存进**图状态**
`state["seen_refs"]`。

```python
from nodes.n08_ref_filter import collect_refs      # 见第 3 节，先把这个文件放进项目

# N05：事实检索
def n05_facts(state: dict) -> dict:
    resp = call_tool("get_company_context", ...)   # 你现有的调用，不要改
    state.setdefault("seen_refs", set()).update(collect_refs(resp))
    state.setdefault("tool_results", []).append(resp)
    return state


# N06：资料检索
def n06_docs(state: dict) -> dict:
    resp = call_tool("get_rule_candidates", ...)   # 你现有的调用，不要改
    state.setdefault("seen_refs", set()).update(collect_refs(resp))
    return state
```

⚠️ **`seen_refs` 必须放在图状态里，不能写成模块级全局变量**——否则并发请求之间会串台。

> 如果你的 N05/N06 是"扣子平台插件节点"而不是自己写的函数，就在该节点之后**串一个代码节点**，
> 用同样的 `collect_refs(上一节点的输出)` 累积到状态里即可。

## 3. 改动三：N08（自检节点）加引用白名单

### 3.1 在本项目里新建文件 `nodes/n08_ref_filter.py`，内容如下（整份复制）

```python
# -*- coding: utf-8 -*-
"""N08 引用白名单：只保留本轮工具响应中真实出现过的引用。

设计要点：
1. 不按字段名硬编码，递归扫描整个工具响应，避免工具增字段后失效；
2. 只做"存在性白名单"，不判断业务对错（业务校验仍由后端负责）；
3. 过滤是纯函数、确定性、可单测；
4. 不抛异常：任何异常都退化为"原样返回"，绝不因为自检节点导致整轮失败。

自测：python -X utf8 nodes/n08_ref_filter.py
"""
from __future__ import annotations

import re

# 规范前缀 + 全部别名（与后端 server/schemas.py 的 REF_ALIASES 对齐）
REF_KINDS = ("ev", "evidence", "metric", "product", "pr",
             "analysis", "an", "compare", "cmp",
             "regional", "rg", "company", "co")

_REF_RE = re.compile(r"^(?:" + "|".join(REF_KINDS) + r"):\S+$")
# evidence 必须四段，且 claim_number 为数字
_EV_RE = re.compile(r"^(?:ev|evidence):[^:]+:\d+:[^:]+$")

# 光球类型（与后端 server/schemas.py::ORB_KINDS 对齐）
ORB_KINDS = ("company", "evidence", "profile", "product",
             "compare", "analysis", "checklist")

MAX_ORBS = 12


def collect_refs(obj, out: set | None = None) -> set:
    """递归收集任意工具响应中所有形如引用的**字符串值**（不含键名）。"""
    if out is None:
        out = set()
    if isinstance(obj, str):
        s = obj.strip()
        if " " not in s and _REF_RE.match(s):
            out.add(s)
    elif isinstance(obj, dict):
        for v in obj.values():
            collect_refs(v, out)
    elif isinstance(obj, (list, tuple, set)):
        for v in obj:
            collect_refs(v, out)
    return out


def _clean_refs(refs, seen: set) -> list:
    """保留白名单内、且 evidence 格式合法的引用；保持原顺序、去重。"""
    out, used = [], set()
    for r in refs or []:
        if not isinstance(r, str):
            continue
        r = r.strip()
        if not r or r in used or r not in seen:
            continue
        if r.startswith(("ev:", "evidence:")) and not _EV_RE.match(r):
            continue
        used.add(r)
        out.append(r)
    return out


def filter_draft_refs(draft: dict, seen: set) -> tuple[dict, list]:
    """按白名单过滤草稿全部引用，返回 (过滤后的草稿, 被剔除的引用列表)。"""
    dropped: list[str] = []

    if not isinstance(draft, dict):
        return draft, dropped
    seen = set(seen or set())

    # 1) 回答块
    for b in draft.get("answer_blocks") or []:
        if not isinstance(b, dict):
            continue
        before = list(b.get("refs") or [])
        b["refs"] = _clean_refs(before, seen)
        dropped.extend([x for x in before if x not in b["refs"]])

    # 2) 推荐：product_ref 非法在后端是 block 级问题，会把整次分析降级为
    #    partial，必须一并过滤（比 evidence_refs 为空更严重）。
    for r in draft.get("recommendations") or []:
        if not isinstance(r, dict):
            continue
        for key in ("evidence_refs", "product_source_refs"):
            before = list(r.get(key) or [])
            r[key] = _clean_refs(before, seen)
            dropped.extend([x for x in before if x not in r[key]])
        pref = r.get("product_ref")
        if pref and pref not in seen:
            r["product_ref"] = None
            dropped.append(pref)

    # 3) 光球：过滤非法 ref_id + 丢弃非法 kind
    orbs = draft.get("orbs")
    if isinstance(orbs, list) and orbs:
        kept = []
        for o in orbs:
            if not isinstance(o, dict):
                continue
            if o.get("kind") not in ORB_KINDS:
                dropped.append(f"orb_kind:{o.get('kind')}")
                continue
            rid = o.get("ref_id")
            if rid and rid not in seen:
                dropped.append(rid)
                continue
            kept.append(o)
        draft["orbs"] = kept[:MAX_ORBS]
        # 关键：不要留"半套"光球——只给 product 球会让后端跳过自动补建，
        # 页面上就没有原文球了。要么全空、要么至少含一个证据球。
        if not any(o.get("kind") == "evidence" for o in draft["orbs"]):
            draft["orbs"] = []

    return draft, dropped


def n08_selfcheck(state: dict) -> dict:
    """LangGraph 节点包装。

    state 约定：
      state["draft"]       必填，N07 产出的 analysis_draft
      state["seen_refs"]   必填，N05/N06 累积的本轮工具引用白名单
      state["clean_draft"] 输出，供 N09 输出
    """
    try:
        draft = state.get("draft") or {}
        seen = state.get("seen_refs") or set()
        draft, dropped = filter_draft_refs(draft, seen)
        if dropped:
            draft.setdefault("warnings", []).append(
                "已剔除 %d 条无法在工具响应中核对的引用（未采纳模型自造的引用）。"
                % len(dropped))
        state["draft"] = draft
        state["clean_draft"] = draft
    except Exception as e:  # noqa: BLE001  自检节点绝不阻断主流程
        state.setdefault("warnings", []).append(f"引用自检跳过（{type(e).__name__}）。")
    return state
```

> 不带自测函数（已经过验证：本模块自测 10/10、单元测试 10 项通过）。

## 6. 排查表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 改完 `refs` 还是空 | `seen_refs` 没传到 N08 | 确认 N05/N06 真的写了 `state["seen_refs"]`，且是**同一个图状态**，不是局部变量 |
| 改了提示词但行为没变 | 提示词粘贴到了错误的节点，或没保存 | 确认改的是 **N07 大模型节点**的系统提示词；确认已保存并重新部署 |
| `orbs` 变成空数组了 | 说明只给了 product 球、被过滤清空 | **这是预期行为**——后端会自动补建；不要"改回去" |
| `status` 变成 `partial` | 有 `bad_product_ref` 等 block 级问题 | 检查 N08 是否真的执行了（它的职责之一就是过滤非法 `product_ref`） |
| 部署后接口 404 `instance_not_found` | 沙箱实例被回收 | 重新部署一次；另外演示前先发一次预热请求 |
