## 四、逻辑回归：出海需求的横截面决定因素

### 4.1 模型设定

采用**面板 Logit 模型**，主模型以 $Deployment_{it}$ 为因变量，估计含年份固定效应的 pooled Logit，并将标准误聚类到企业。设线性预测函数为 $\eta_{it}=f(X_{it},\gamma_t)$，则模型可写为：

$$
\begin{aligned}
\Pr\!\left(Deployment_{it}=1\mid X_{it},\gamma_t\right)
&=\Lambda(\eta_{it})
=\frac{\exp(\eta_{it})}{1+\exp(\eta_{it})}.
\end{aligned}
$$

其中，线性预测函数为：

$$
\begin{aligned}
\eta_{it}
&=f(X_{it},\gamma_t)\\
&=\beta_0
+\beta_1\ln(\mathrm{Assets}_{it})
+\beta_2 \mathrm{Age}_{it}
+\beta_3 \mathrm{ROA}_{it}
+\beta_4 \mathrm{Leverage}_{it}\\
&\quad
+\beta_5 \mathrm{RDIntensity}_{it}
+\beta_6 \mathrm{Coastal}_{i}
+\beta_7 \mathrm{TFPR}_{it}
+\beta_8 \mathrm{SOE}_{it}\\
&\quad
+\beta_9 \mathrm{OverseasSub}_{i,t}
+\beta_{10}\ln(\mathrm{1+OverseasSubCount}_{i,t})
+\gamma_t .
\end{aligned}
$$

其中，
- Λ(·) 为逻辑斯蒂累积分布函数；
- $OverseasSub_{i,t}$ 表示当年是否拥有海外子公司；
- $ln(OverseasSubCount_{i,t})$ 表示当年海外子公司规模的自然对数转换；
- $λ_t$ 为年份固定效应；
- ε_it 为残差项

### 4.2 系数解释与预期

| 变量                          | 预期方向 | 经济含义                                 |
| --------------------------- | ---- | ------------------------------------ |
| $ln({Assets}_{it})$（规模）     | +    | 规模越大，越有资源和能力出海                       |
| $Age_{it}$（企业年龄）            | ±    | 年龄可积累市场经验和组织惯例，也可能带来路径依赖与组织惰性        |
| $ROA_{it}$（盈利能力）            | +    | 盈利能力越高，越有利于承担海外进入成本                  |
| $Leverage_{it}$（杠杆率）        | -    | 债务负担与融资约束可能压缩企业用于海外组织部署的可支配资源。       |
| $RDIntensity_{it}$（研发强度）    | +    | 技术密集型更倾向海外扩张                         |
| $Coastal_{i}$（沿海地区）         | +    | 区位便利，出海需求更强                          |
| $TFPR_{it}$（生产率）            | +    | 生产率高，越可能跨过出海门槛（Melitz）               |
| SOE（国有）                     | ±    | 国企出海受政策引导，方向待检验                      |
| OverseasRevShare（海外收入占比）    | +    | 已有国际化基础，继续深化                         |
| $OverseasSub_{it}$          | +    | 既有海外组织可带来制度知识、当地网络和管理经验，降低后续部署的边际成本。 |
| $ln(OverseasSubCount_{it})$ | +    | 更大的既有海外网络代表更深的国际化经验与协调能力.            |

### 4.4 稳健性

#### **4.4.1 代理变量替换**
以注册资本对数替代资产总额后，当年海外子公司规模的 OR 为 2.384（p<0.001），当年是否已有海外子公司仍为正但不显著（p=0.137）。注册资本本身不显著（p=0.966），说明主结论不依赖于具体的规模口径。

#### 4.4.2 研发口径与正交化
用研发/资产替代研发/营收后，研发变量不显著（p=0.955）；将研发强度对资产规模和沿海地区正交化后，残差项仍不显著（p=0.970）。因此，研发不显著并非由“研发/营收”分母或与规模、沿海地区的线性共线性简单造成；在本行业中，该代理可能不足以度量海外进入所需的技术壁垒。

#### 4.4.3 国际化网络的替代测度
以当年海外国家广度替代子公司状态与规模后，该变量显著为正（系数=1.184，OR=3.266，p<0.001）。这表明核心关联不取决于“子公司数”这一单一网络口径。

#### 4.4.4 模型交叉验证
同规格的 LPM 与 Probit给出相同方向；条件 Logit 仅利用企业内部标签切换，当年海外子公司规模仍为正且边际显著（OR=1.917，p=0.056）。企业—年份双向固定效应 LPM 中，资产规模为边际正向（p=0.064），海外子公司规模也为边际正向（系数=0.111，p=0.073），而“是否已有海外子公司”不显著（p=0.764）。这说明当期网络规模的主关联并非完全来自企业间截面差异。

| t+2 海外子公司增加 | 0.549（1.731；0.028） | 0.383（1.467；0.109） | 0.504 |
| t+2 严格首次进入 | -0.218（0.804；0.792） | 2.540（12.684；<0.001） | 0.005 |

最强的梯度结果出现在 t+2 严格首次进入：仅战略意图没有预测作用，经营部署的 OR 为 12.68，且其系数显著高于仅战略意图（Wald p=0.005）。企业与年份双向固定效应 LPM 也显示，Stage 每提高一级，t+1 海外子公司增加概率提高 5.15 个百分点（p=0.028）。

## 八、本环节对指标验证的意义

1. **描述性统计 + 时空分布 + 分组检验**：证明指标分布符合理论预期（大企业、沿海、外向型行业需求强；需求随年份应呈递增），间接验证指标有效性；
2. **经典句例 + 行为验证**：从微观句子层面直接证明"识别到的高置信需求句确实对应强出海表现"，是指标效度的最直观证据；
3. **识别性能**：Accuracy/Kappa 等硬指标证明大模型识别的可靠性，可复现、可审计；
4. **前瞻效度检验**：证明指标测度的是事前的海外组织部署/进入需求，而不是同期经营结果；且对企业未来出海行为有显著预测力；
5. **承诺深度梯度**：指标并非简单捕捉泛化国际化表态，而能够刻画从无需求、战略意图到可核验部署的承诺深化。
